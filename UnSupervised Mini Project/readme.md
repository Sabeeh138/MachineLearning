# 🛍️ Customer Segmentation using k-Means

This is a sleek and interactive machine learning web app built with **Streamlit** that helps businesses **understand their customers better** through **k-Means clustering**. Whether you're a data scientist, marketer, or just curious, this app helps you uncover hidden customer groups—without writing a single line of code beyond running the app.

---

## 🚀 What Can This App Do?

Imagine knowing:
- Which customers are your **biggest spenders**?
- Who shops often but spends less?
- Which age groups are most active?

This app lets you do exactly that with just a **CSV file and a click**.

✨ **Key Features**:
- Upload your own customer dataset or use the built-in demo
- Select which customer features to analyze (like Age, Income, Spending Score)
- Discover the **ideal number of customer groups** using the **Elbow Method**
- Visualize your customer segments beautifully in 2D using PCA
- Instantly **download your segmented data** for marketing or analysis

---

## 🧠 Built With

This project blends **machine learning** with a modern, no-hassle interface. Here’s what powers it:

- 🎈 **Streamlit** – makes data science look beautiful
- 🧠 **scikit-learn** – powers clustering and dimensionality reduction
- 📊 **Seaborn & Matplotlib** – for elegant and meaningful visuals
- 🐼 **Pandas & NumPy** – for smooth data handling

---

## 📥 Output You Get

Once clustering is complete, the app provides:
- A CSV file with your customer data labeled by cluster
- A 2D plot showing the distinct customer segments
- A cluster summary table to understand average spending, income, etc.
